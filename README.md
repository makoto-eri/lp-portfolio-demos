# LP制作ポートフォリオ

ココナラ等で制作例として案内するための、自主制作LPデモ集です。

- 実在する顧客案件、店舗、人物、料金、実績ではありません。
- フォームや予約CTAはデモ表示で、情報の送信・予約は行いません。
- 検品メモ、ヒアリング内容、納品ZIPなどの内部資料は公開対象に含めていません。
- 検索結果で架空店舗と誤認されないよう、各ページに `noindex, nofollow` を設定しています。

「画像LP」は、ページの見た目をAI生成画像の縦スライスで構成し、CTA・価格・主要文言だけをHTMLで重ねる作り方です。手描きのCSSでは再現しにくい質感（箔押し・和紙・筆文字）を出しつつ、文言の修正には即日対応できるようにしています。焼き込んだ文言はすべて `alt` に収めています。

コード・文章・画像の再利用を許諾するライセンスは付与していません。
